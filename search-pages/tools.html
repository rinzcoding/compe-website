CompE Guide - Tools

VS Code

Coding. Free code editor for web, Python, C/C++, and more.

Git and GitHub

Coding. Track your code changes and build a public portfolio.

Python

Programming language. Beginner-friendly language for scripting, automation, and AI.

C / C++

Programming language. Close to the hardware, used in embedded systems and operating systems.

Arduino IDE and boards

Hardware. Cheap microcontroller boards for learning electronics and embedded code.

Tinkercad Circuits

Simulation. Free online tool to build and test circuits and Arduino projects without parts.

Logisim Evolution

Simulation. Design and test digital logic circuits visually.

LTspice

Simulation. Free circuit simulator for analyzing analog electronics.

Raspberry Pi

Hardware. Small, affordable computer for Linux, IoT, and robotics projects.

Linux (Ubuntu)

Operating system. Common in servers and embedded systems. Practice the command line early.
